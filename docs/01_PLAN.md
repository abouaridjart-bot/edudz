# 01_PLAN — مخطط الخطوات

قاعدة: لا انتقال لمرحلة قبل تحقق «معيار الإنجاز» لسابقتها، وتحديث `HANDOFF.md` عند نهاية كل مرحلة.

## المرحلة 0 — التدقيق والتهيئة
- تحقق من وجود ملفات الحزمة، وأنشئ المشروع (`create-next-app` في البيئة السحابية).
- ضبط TypeScript strict وESLint وPrettier وVitest، و`.env.example`، وسكربتات `package.json`.
- اربط قاعدة PostgreSQL المستضافة، وجرّب `prisma migrate`.
- **الإنجاز:** صفحة رئيسية تعمل، `npm run build` ينجح، اتصال DB يعمل.

## المرحلة 1 — الأساس
- نظام التصميم: ألوان، خط Cairo/Tajawal، مكوّنات shadcn بـ RTL، وضع فاتح/داكن.
- i18n (ar/fr)، تنسيق التواريخ والأرقام والعملة (DZD)، المنطقة الزمنية.
- هياكل التخطيط: واجهة عامة، لوحة الطالب، لوحة المركز، لوحة المشرف.
- Prisma: النماذج الأساسية + `seed:base` (الولايات، الأطوار، المستويات، الشعب، المواد).
- **الإنجاز:** تنقّل RTL كامل، البيانات التمهيدية تُحمّل، 10 اختبارات وحدة للأدوات المساعدة.

## المرحلة 2 — الهوية والصلاحيات والمراكز
- تسجيل/دخول (هاتف أو بريد + كلمة مرور، إعادة تعيين)، جلسات آمنة، حد للمحاولات.
- الأدوار: SUPER_ADMIN, CENTER_OWNER, BRANCH_MANAGER, SECRETARY, TEACHER, STUDENT, PARENT.
- Multi-tenant: `Center` و`Branch`، طبقة `tenant.ts`، سياسات صلاحيات مركزية (`can(user, action, resource)`).
- دعوة المستخدمين، ربط ولي بأبنائه.
- **الإنجاز:** اختبارات تثبت أن مستخدم مركز لا يرى بيانات مركز آخر، وأن كل دور محصور بصلاحياته.

## المرحلة 3 — المنهاج والمحتوى التعليمي (الجزء أ)
- إدارة: المستويات/الشعب/المواد/الوحدات (CRUD للمشرف مع بيانات تمهيدية).
- الدروس: نص منسّق (Markdown/MDX)، فيديو مضمّن (روابط خارجية)، ملفات PDF، وسوم، مستوى صعوبة.
- أرشيف الامتحانات: BEM/BAC/نهاية الابتدائي حسب السنة والمادة والشعبة، مع الحلول.
- تصفح وبحث وتصفية عامة، صفحات SEO بالعربية، خريطة الموقع.
- نظام النشر: مسودة ← مراجعة ← منشور؛ رؤية PUBLIC/CENTER/GROUP.
- **الإنجاز:** مشرف ينشر درساً وأرشيف امتحان، وطالب يتصفحه ويبحث فيه.

## المرحلة 4 — التفاعل التعليمي
- اختبارات قصيرة (اختيار متعدد، صح/خطأ، إدخال قصير) بتصحيح تلقائي ومحاولات متعددة.
- واجبات: تسليم نص/ملف، تصحيح الأستاذ، علامة /20 وملاحظات.
- تتبّع التقدم: دروس مكتملة، نتائج، نقاط ضعف حسب الوحدة.
- أسئلة وأجوبة على الدرس (إشراف من الأستاذ).
- **الإنجاز:** مسار كامل: درس ← اختبار ← نتيجة ← تقدم ظاهر في لوحة الطالب وولي الأمر.

## المرحلة 5 — جناح المركز: الكيانات
- الفروع والقاعات (سعة، تجهيزات).
- الطلاب (بطاقة، مستوى، شعبة، مدرسته الأصلية)، الأولياء، الأساتذة (مواد ومستويات).
- الأفواج: مادة + مستوى + أستاذ + قاعة + سعة + خطة رسوم؛ التسجيل في الأفواج مع قائمة انتظار.
- استيراد CSV للطلاب مع تقرير أخطاء.
- **الإنجاز:** مدير فرع يسجّل طالباً في فوج، وتُمنع الزيادة عن السعة.

## المرحلة 6 — الجداول والحضور
- جدول أسبوعي دوري للأفواج، مع توليد الحصص، وكشف التعارض (قاعة/أستاذ/فوج/طالب).
- حصص استثنائية، إلغاء، تعويض، عطل ومناسبات.
- تسجيل الحضور (حاضر/غائب/متأخر/معذور) من الهاتف، وQR اختياري لبطاقة الطالب.
- تنبيه الولي بالغياب (قالب رسالة جاهز + رابط WhatsApp/SMS عبر محوّل قابل للاستبدال).
- **الإنجاز:** جدول بلا تعارض، حضور يُسجَّل مرة واحدة لكل طالب/حصة، تقرير غياب شهري.

## المرحلة 7 — الفوترة والمدفوعات وأجور الأساتذة
- خطط رسوم: شهري/بالحصة/بالفصل/بالحزمة، خصومات (أخوة، منحة)، رسوم تسجيل.
- فواتير شهرية تُولَّد من التسجيل (قابلة لإعادة التوليد بأمان)، دفعات جزئية، إيصال قابل للطباعة بالعربية.
- متأخرات وتذكيرات، صندوق يومي وإقفاله.
- عقود الأساتذة: نسبة من الرسوم أو أجر بالساعة/الحصة؛ كشف أجور شهري؛ سلف.
- المصاريف (إيجار، كهرباء، …)، وهامش الربح بالفرع.
- محوّل دفع إلكتروني (واجهة فقط) لـ CIB/Edahabia/BaridiMob عند توفر مزوّد؛ لا تنفيذ وهمي.
- **الإنجاز:** دورة كاملة: فاتورة ← دفعة جزئية ← إيصال ← إقفال صندوق؛ كل الأرقام مطابقة في اختبارات.

## المرحلة 8 — التقارير والإشعارات
- لوحات: الإيرادات، المتأخرات، الحضور، امتلاء الأفواج، أداء الأساتذة، تسرّب الطلاب.
- تصدير CSV/Excel/PDF (طباعة عربية سليمة عبر CSS للطباعة).
- مركز إشعارات داخلي + قوالب رسائل.
- **الإنجاز:** كل تقرير يطابق بيانات الاختبار، والتصدير يفتح بخط عربي صحيح.

## المرحلة 9 — الأداء والأمان والنشر
- PWA (تثبيت، تخزين مؤقت للصفحات العامة)، تحسين الصور، تقسيم الشيفرة.
- تدقيق أمني (انظر `05_QA_SECURITY.md`)، نسخ احتياطي لقاعدة البيانات، سجل تدقيق.
- اختبارات E2E للمسارات الحرجة، توثيق التشغيل.
- نشر على Vercel + ربط نطاق + مراقبة أخطاء.
- **الإنجاز:** قائمة QA كاملة خضراء، موقع منشور، `HANDOFF.md` مكتمل.
