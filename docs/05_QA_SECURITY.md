# 05_QA_SECURITY — الجودة والأمان والنشر

## 1. قائمة الأمان
- [ ] كلمات المرور مجزّأة (argon2 عبر `@node-rs/argon2` أو bcryptjs)، حد أدنى للطول، حد لمحاولات الدخول.
- [ ] جلسات HttpOnly + Secure + SameSite، وتدوير عند تغيير كلمة المرور.
- [ ] كل Server Action تمرّ بـ: مصادقة ← صلاحية ← Zod ← نطاق المركز ← تدقيق.
- [ ] اختبار آلي للعزل بين المراكز، واختبار مصفوفة الأدوار.
- [ ] رؤوس الأمان: CSP, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, HSTS.
- [ ] رفع الملفات: قائمة أنواع مسموحة، حد للحجم، أسماء عشوائية، تخزين خارج الجذر العام، فحص MIME.
- [ ] تنظيف محتوى Markdown/MDX المقدَّم من المستخدمين (منع XSS)؛ MDX لا يُقبل إلا من الأدوار الموثوقة.
- [ ] لا أسرار في المستودع؛ `.env.example` فقط؛ تدوير المفاتيح موثّق.
- [ ] حماية روابط الملفات الخاصة (روابط موقّعة قصيرة العمر).
- [ ] سجل تدقيق للمالية والحضور والصلاحيات والحذف، غير قابل للتعديل من الواجهة.
- [ ] بيانات القاصرين: أقل بيانات، موافقة الولي عند التسجيل، تصدير/حذف عند الطلب.

## 2. قائمة الجودة
- [ ] `npm run lint` و`tsc --noEmit` و`npm test` و`npm run build` تنجح.
- [ ] اختبارات وحدة: المال، التعارض، الفوترة، التطبيع العربي، الصلاحيات.
- [ ] اختبارات تكامل على قاعدة بيانات اختبار منفصلة (فرع Neon/Supabase مخصّص).
- [ ] E2E: دخول ← تسجيل طالب ← فوج ← حصة ← حضور ← فاتورة ← دفعة ← إيصال.
- [ ] فحص RTL: لا نصوص مقطوعة، الجداول والنماذج والأيقونات صحيحة الاتجاه.
- [ ] فحص الهاتف 360px و768px و1280px.
- [ ] وصولية: تباين AA، تنقل لوحة المفاتيح، `aria-label` للأزرار الأيقونية.
- [ ] أداء: Lighthouse للصفحات العامة، لا استعلامات N+1 (راجع سجل Prisma).
- [ ] طباعة الإيصال وكشف الأجور بخط عربي سليم.

## 3. النشر على المتصفح (بلا Docker)
1. مستودع GitHub.
2. قاعدة Neon/Supabase: أنشئ فرعين: `production` و`preview/test`.
3. Vercel: اربط المستودع، أضف متغيرات البيئة، شغّل `prisma migrate deploy` ضمن أمر البناء.
4. نطاق مخصص + HTTPS تلقائي.
5. مراقبة الأخطاء (Sentry خطة مجانية) وسجلات Vercel.
6. نسخ احتياطي: فعّل النسخ اليومي لدى المزوّد، وجرّب الاسترجاع مرة قبل الإطلاق.
7. قائمة الإطلاق: بيانات demo غير موجودة، حساب SUPER_ADMIN بكلمة مرور قوية، سياسة الخصوصية وشروط الاستخدام منشورة.
